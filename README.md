# 💕 Bizim En'lerimiz

Kağan & Gül için hazırlanmış, GitHub Pages üzerinde çalışabilen mini anı/cevap uygulaması.

## Özellikler

- 80+ soru
- Kağan ve Gül için ayrı cevap alanları
- Kategori filtreleri
- İlerleme yüzdesi
- Otomatik `localStorage` kaydı
- Mobil uyumlu tasarım
- Harici backend gerektirmez

## GitHub Pages ile yayınlama

1. Bu klasördeki dosyaları GitHub repository'nize yükleyin.
2. Repository → **Settings** → **Pages** bölümüne gidin.
3. **Deploy from a branch** seçin.
4. Branch olarak `main`, klasör olarak `/ (root)` seçin.
5. Save'e basın.
6. GitHub size sitenizin adresini verecektir.

## Önemli

Bu ilk sürüm cevapları **tarayıcıdaki localStorage** alanında tutar.
